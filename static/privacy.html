Privacy Policy

Last updated: 6 September 2026

What ARJUNA AI stores

ARJUNA AI stores operational metadata required to run the gateway, including API-key identifiers, provider/model route, token counts when reported, request latency, status and timestamps.

Prompt content

The core gateway does not persist prompts or model responses in its usage database. Requests are sent to the model provider you select or the router selects, and that provider's own terms and privacy policy apply.

Secrets

Provider API secrets are server-side configuration. Generated ARJUNA API keys are stored as one-way keyed hashes; the plaintext secret is shown only when created.

Security and logs

Infrastructure logs may contain technical metadata such as IP address, endpoint, status code and request identifiers. Do not place secrets in prompts, URLs or loggable headers beyond the documented Authorization header.
